# App workspace

FastAPI services live in `main.py` (main API) and `router_api.py`. Shell helpers start and stop those processes plus nginx (`start_*.sh`, `stop_*.sh`, `status_*.sh`).

**New here?** Start with [docs/SETUP.md](docs/SETUP.md) for install, model bootstrap, and how to run the server.

For local model setup and weights, see `LOCAL_MODELS.md`. Python dependencies are listed in `requirements.txt`.
